# ABYSS / LAST LIGHT UI 미리보기

`index.html`을 브라우저에서 열면 됩니다. 설치, 서버, 인터넷 연결은 필요하지 않습니다.

## 한글 UI

목표·재료·메뉴·조작안내·인벤토리·회수·종료·알림 문구를 한글로 표시합니다. 전력 전지(침수 연구소), 선체 합금(난파선 묘지), 추진 부품(펌프장)을 각각 2개씩 수집하며 목표 패널에 현재 수량, 수리 완료 상태, 다음 수리 단계를 표시합니다. 단축키와 브랜드명 ABYSS는 유지합니다.

`ko.js`는 기존 영문 상태 및 저장 기록의 표시 문구를 번역하고, `korean.css`는 한글 글꼴과 목표 패널 배치를 담당합니다. 내부 상호작용 식별자는 유지하여 기존 이어하기 기록을 사용할 수 있습니다. 한글 적용 범위는 이 HTML 미리보기입니다.

## 시작화면

처음 열면 어두운 바다와 거대한 생물의 그림자가 지나가는 시작화면이 표시됩니다. 새로하기, 이어하기, 게임 종료, 조작안내를 제공합니다. ESC 또는 상단 시작화면 버튼으로 돌아갑니다. 시간은 플레이 화면 상단 중앙에 `00:00` 숫자만 표시됩니다.

새로하기로 시작한 HTML 미리보기는 자원·수리 상태·경과 시간·인벤토리 배치를 브라우저 저장소에 자동 저장합니다. 이어하기는 같은 브라우저와 파일 경로에 저장된 기록이 있을 때 활성화됩니다. 메뉴에서는 시간이 멈춥니다. 화면 상태 선택은 독립적인 UI 확인용으로, 기존 잠수 저장을 덮어쓰지 않습니다. 저장소를 사용할 수 없는 환경에서는 저장 실패 안내를 표시합니다. Unreal 게임 세이브와는 연결되지 않습니다.

게임 종료는 종료 안내를 표시합니다. 스크립트로 열린 창은 닫기를 시도하고, 일반 탭은 브라우저 제한에 따라 사용자가 직접 닫아야 합니다. 조작안내는 게임 조작표와 HTML 미리보기의 차이를 함께 표시합니다.

`menu.js`는 메뉴와 저장·복원을, `menu.css`는 시작화면 및 바다 연출을 담당합니다. 그림자는 SVG 실루엣과 CSS 애니메이션으로 구현해 외부 이미지나 네트워크가 필요 없습니다. 모션 감소 설정에서는 그림자가 정지합니다.

- `index.html`: 화면 선택 및 상태 조절 패널
- `styles.css`: 1600×900 기준 HUD 레이아웃과 반응형 축소
- `app.js`: 화면 상태, 상호작용, 회수 타이밍 미리보기
- `inventory.js`: 7×7 격자 수납, 공간 검사와 아이템 이동
- `hologram.css`: 홀로그램 효과와 새 인벤토리 레이아웃

## 홀로그램 UI와 격자 수납

수집목표 패널은 현재 **왼쪽 상단**에 있습니다. 회수 성공·제작 완료·수리 완료 알림은 그 아래에 표시되고, 각 알림은 발생 시점에서 **5초 뒤** 사라집니다. 연속 이벤트는 최대 3개까지 따로 표시하며 각자의 표시 시간을 유지합니다. 제작 완료는 화면 상태의 `제작 완료 알림`에서 확인할 수 있으며 실제 제작 레시피 시스템을 추가한 것은 아닙니다. 메뉴 이동·새로하기·화면 상태 변경 시 임시 알림을 초기화하고 저장 기록에는 넣지 않습니다.

현재 플레이 화면의 상시 HUD는 **오른쪽 상단 수집·수리 목표 패널과 상단 중앙 숫자 시간**만 표시합니다. 산소바, 배터리, 체력바, 지도, 깊이, 조작 키, 접근 경고 등의 상시 표시는 제거했습니다. 상호작용 안내·회수 타이밍·수리 진행·종료 화면은 해당 상황에서만 표시됩니다. 자원 관련 알림은 인벤토리 하단에서 확인합니다.

TAB으로 인벤토리를 열면 산소는 **원형 게이지**, 후레쉬 배터리는 **직선 게이지**로 표시합니다. 산소 %, 예비 산소통 수량, 배터리 %·남은 시간·조명 상태, 체력은 인벤토리 내부에서만 확인할 수 있습니다. 하단의 별도 상태 조절 패널은 HTML 미리보기 편집용이며 게임 HUD가 아닙니다.

화면 상단 중앙의 잠수 경과 시간이 초 단위로 갱신됩니다. 종료 화면에서는 멈추며 상태를 다시 선택하면 해당 상태의 시간에서 시작합니다.

장비창은 7열 × 7행, 총 49칸입니다. 산소통은 개당 가로 2 × 세로 2칸, 후레쉬는 가로 3 × 세로 1칸, 수리 부품은 개당 1칸을 차지합니다. 아이템은 쌓이지 않고 개별 수납됩니다. 아이템을 드래그하거나 아이템 선택 후 목적지 칸을 클릭하면 이동합니다. 클릭 배치의 목적지는 아이템의 왼쪽 위 칸입니다. 겹침 및 경계 밖 이동은 거부합니다. 배치는 장비창을 닫았다 열어도 유지되며 화면 상태 선택·초기화 시 재설정됩니다.

수량 조절·수집 시 연속된 빈 공간에 자동 수납하고, 공간이 부족하면 실제 수납 가능한 수량으로 되돌리며 안내합니다. 산소통 사용과 수리 부품 소비도 격자에 반영됩니다. 후레쉬는 항상 인벤토리에 한 개 존재합니다.

패널에는 반투명 청록색 유리, 발광 윤곽선, 스캔라인, 미세한 밝기 변화를 적용했습니다. 운영체제의 모션 감소 설정에서는 패널 애니메이션을 끕니다. 이 변경은 HTML 미리보기에 적용되며 Unreal 게임의 인벤토리 로직은 변경하지 않습니다.

## 확인 방법

상단의 **화면 상태**에서 기본 HUD, 시작 안내, 장비창, 자원 부족, 부품 부족/준비, 회수, 은신, 조명, 실내, 이동, 추적, 단계별 수리, 탈출구, 성공/실패를 선택합니다. 하단에서 자원과 부품 수량을 바꿀 수 있습니다.

미리보기 영역을 클릭한 후 TAB으로 장비창, Q로 산소 보충, F로 조명, SPACE로 회수 판정, E로 상호작용, R로 초기화합니다. 입력칸·버튼에 포커스가 있으면 기본 브라우저 키 동작을 유지합니다. 회수 이벤트는 2.4초, 성공 구간은 45–62%입니다. 시간 초과 후에는 화면 상태에서 다시 선택해 재시도합니다.

## 원본과 대응

원본: `../Source/mama/AbyssGame.cpp`의 `AAbyssHUD::DrawHUD()` 및 `AAbyssGameMode::SitePrompt()`, 상태 정의: `../Source/mama/AbyssGame.h`.

| HTML 구성 | 게임 HUD |
| --- | --- |
| oxygen / status / health | 산소, 배터리, 깊이, 조명, 체력 |
| restore / repair | 3단계 수리 목표와 진행 막대 |
| radar | 방위, 잠수함, 부품, 대피소, 플레이어, 경고 시 추적자 |
| notice / prompt / alert | 알림, 근접 상호작용, 접근·추적 경고 |
| equipment | 장비, 부품 보관, 부족/준비/온라인, 예비 산소통 경고 |
| salvage | 회수 타이밍 이벤트 |
| ending | 탈출 성공, 산소 고갈 및 체력 소진 실패 |
| keys / timer | 조작법과 잠수 시간 |

이 폴더는 독립적인 HTML 미리보기입니다. Unreal의 Canvas HUD를 교체하거나 게임 상태를 실시간으로 연결하지 않습니다. 수중 배경과 레이더 위치는 예시이며 실제 게임 캡처가 아닙니다. C++ 글꼴·색상 렌더링과 HTML 렌더링에는 차이가 있습니다. 수리는 미리보기에서 E로 단계를 완료하며 실제 게임의 4초 대기와 거리 판정은 시뮬레이션하지 않습니다. 장비창의 자원·부품은 하단 조절 패널과 즉시 동기화됩니다.
